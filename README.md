# Пермский транспорт — веб-версия

Демонстрационная веб-версия мобильного приложения «Пермский транспорт»: оплата проезда,
транспортные карты, расписание и личный кабинет. Приложение целиком работает в браузере,
без бэкенда — все данные хранятся локально в `localStorage`.

Интерфейс собран под мобильный экран и рассчитан на добавление на домашний экран iPhone
(веб-клип в полноэкранном режиме).

## Возможности

**Билеты**
- цифровая транспортная карта: две карты в карусели (гражданская ЕТК и цифровая с балансом)
- оформление заказа: QR-сканер, ввод гос. номера ТС, выбор ТС на карте, поиск по Bluetooth
- выбор маршрута из полного списка Перми (76 автобусных и 7 трамвайных) с поиском по номеру
- заказ билетов с обратным отсчётом 60 секунд, оплата и электронный билет
- оплаченный билет: секундомер «Время в пути», QR-код, кнопка «Контроль», чек
- история заказов и детали каждого заказа
- оценка поездки по семи критериям

**Проездной**
- карусель транспортных карт, баланс, активные проездные
- пополнение, покупка проездного, история операций
- добавление пластиковой карты по номеру

**Расписание**
- выбор даты, типа транспорта, маршрута, направления и остановки
- карта остановок с прибытиями и избранное

**Кабинет**
- профиль, тарифное меню, пункты выдачи, правила пересадки, порядок оформления ЛПД
- новостная лента, счета СБП, поддержка, настройки оформления

**Оформление**
- светлая и тёмная темы, по умолчанию — как в системе
- цвет статус-бара подстраивается под тему

## Запуск

Нужен любой статический сервер — файлы нельзя открывать по `file://`,
иначе не сработают запросы к иконкам и картам.

```bash
python tools/server.py 8931
```

Затем открыть `http://localhost:8931`.

Альтернативы:

```bash
python -m http.server 8931
```

```bash
npx --yes serve -l 8931 .
```

### Добавление на домашний экран iPhone

Открыть сайт в Safari → «Поделиться» → «На экран «Домой»». Приложение запустится
в полноэкранном режиме, без адресной строки, с иконкой транспортной карты.

## Технологии

Без сборки и зависимостей: чистые HTML, CSS и JavaScript.
Карты — [Leaflet](https://leafletjs.com/) с тайлами OpenStreetMap (подключается по CDN).

Список маршрутов взят с официального сайта [МКУ «Гортранс»](https://www.m.gortransperm.ru/routes-list/0/)
(76 автобусных и 7 трамвайных маршрутов). Остановки, перевозчики, адреса пунктов выдачи
и история поездок — демонстрационные.

Состояние приложения (карты, заказы, избранное, тема) лежит в `localStorage`
под ключом `permtransport.state.*`. Сброс к демо-данным — «Кабинет» → шестерёнка →
«Сбросить демо-данные».

## Публикация на GitHub Pages

1. Создать репозиторий и загрузить в него содержимое папки.
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Сборка не требуется — репозиторий публикуется как есть.
