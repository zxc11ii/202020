# Шлюз доступа (коды + привязка к устройству)

Приложение остаётся статикой; перед ним стоит Nginx, который отдаёт файлы
только после входа по коду. Коды выпускаются в админке `/admin`.

**Правила**
- Один код — одно устройство. У iPhone Safari и «иконка на экране Домой» — разные
  хранилища cookie, поэтому у кода 2 слота (`MAX_DEVICES=2`).
- Вход живёт 90 дней (`SESSION_DAYS`). Когда истечёт — вводится тот же код.
- Код на чужом устройстве → «уже используется на другом устройстве».
- В админке код можно **отвязать** (человек сменил телефон), **отозвать**, **удалить**.
- Ссылка `https://домен/login?code=XXX-XXX-XXX` — подставляет код автоматически.

## Установка на сервер (Ubuntu, от root)

Нужен домен, указывающий на сервер. Если своего нет — бесплатно работает
`72-56-28-97.sslip.io` (sslip.io превращает IP в домен, Let's Encrypt его принимает).

```bash
git clone https://github.com/zxc11ii/202020.git /var/www/permtransport
DOMAIN=72-56-28-97.sslip.io bash /var/www/permtransport/server/deploy/install.sh
```

Скрипт поставит nginx, python venv, certbot; создаст `/etc/permtransport.env`
с секретом и **паролем администратора (он будет напечатан в конце — сохраните)**.

Потом:
1. Откройте `https://ДОМЕН/admin` (логин любой, пароль из вывода скрипта).
2. Создайте коды, раздайте людям код или ссылку.
3. Человек открывает `https://ДОМЕН`, вводит код → «Поделиться → На экран Домой».

## Обновление после `git push`

```bash
bash /var/www/permtransport/server/deploy/update.sh
```

## Полезное

- Логи: `journalctl -u permtransport -f`, `tail -f /var/log/nginx/error.log`
- База кодов: `/var/lib/permtransport/access.db` (SQLite) — её и `/etc/permtransport.env` стоит бэкапить.
- Если порт 80/443 занят другим сервисом на этом сервере, `nginx -t` это покажет.
